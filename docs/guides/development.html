Repository Layout

  • crates/voicelayer-core: shared domain types, config loading, and UDS HTTP/SSE client
  • crates/voicelayerd: daemon, cpal audio capture, dictation orchestrators, and /v1 HTTP API
  • crates/voicelayer-cli: operator CLI and foreground push-to-talk TUI (binary: vl)
  • crates/voicelayer-desktop: multi-window iced GUI shell (binary: vl-desktop)
  • crates/voicelayer-ui: shared UI theme tokens and typography constants
  • crates/voicelayer-testkit: shared doc-parsing utilities for integration guard tests
  • python/voicelayer_worker: stdio JSON-RPC worker, Silero VAD pre-pass, and ASR/LLM provider drivers
  • openapi/voicelayerd.v1.yaml: OpenAPI 3.1 contract for the daemon control plane
  • systemd/ and launchd/: Linux systemd user units, environment template, and macOS LaunchAgent plist
  • scripts/: installer, whisper-server wrapper, and whisper latency benchmark scripts

Verification Chain

Run the full verification sequence before opening or merging a pull request (also mirrored in README.md, CLAUDE.md, and CI):

cargo fmt --all
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all
uv sync --group dev
uv run ruff check python tests/python
uv run ruff format --check python tests/python
uv run pytest -q tests/python

Daemon Socket

Default socket location:

$XDG_RUNTIME_DIR/voicelayer/daemon.sock

When XDG_RUNTIME_DIR is unset (for example on macOS), the daemon and clients fall back to $TMPDIR/voicelayer/daemon.sock. Override with VOICELAYER_SOCKET_PATH.

Worker Project Root

voicelayerd locates python/voicelayer_worker using VOICELAYER_PROJECT_ROOT, falling back to the current working directory when unset. From the repository root:

cargo run -p voicelayerd

To enable composition, rewrite, and translation, configure VOICELAYER_LLM_ENDPOINT and VOICELAYER_LLM_MODEL (see LLM Provider). To enable ASR, configure whisper.cpp or an optional GPU backend (see ASR Providers).

Operational Notes

  • Contract and documentation guard tests live in crates/voicelayer-core/tests/openapi_contract_guards.rs, crates/voicelayer-core/tests/repo_consistency_guards.rs, crates/voicelayer-core/tests/doc_consistency_guards.rs, crates/voicelayerd/tests/api_contract_guards.rs, crates/voicelayerd/tests/worker_protocol_guards.rs, and crates/voicelayer-cli/tests/cli_doc_guards.rs.
  • compose, rewrite, and translate call an OpenAI-compatible endpoint via python/voicelayer_worker/providers/openai_compatible.py. Unconfigured endpoints return JSON-RPC -32004; runtime failures return -32005.
  • transcribe runs the optional Silero VAD pre-pass in python/voicelayer_worker/pipeline.py before dispatching to whisper-server, whisper-cli, MiMo-V2.5-ASR, or Qwen3-ASR-1.7B. VAD failures annotate notes and fall back to the raw WAV.
  • Live dictation runs via POST /v1/sessions/dictation and POST /v1/sessions/dictation/stop. StartDictationRequest.segmentation selects {"mode": "one_shot"} (default), {"mode": "fixed", "segment_secs": N}, or {"mode": "vad_gated", "probe_secs": P, "max_segment_secs": M, "silence_gap_probes": G}.
  • Passing --duration-seconds N to vl dictation start waits N seconds after listening begins, stops the session automatically, and prints the final DictationCaptureResult.
  • vl dictation list calls GET /v1/sessions and shows all sessions seen since daemon startup so lost session IDs can be recovered.
  • vl dictation foreground-ptt opens a terminal-local push-to-talk panel. When the terminal supports keyboard release events it records while held; otherwise it toggles on press. Inside the panel: scroll with j/k, arrows, or PageUp/PageDown; press c to copy, r to restore clipboard text, i to re-inject, s to save under $XDG_STATE_HOME/voicelayer/transcripts/ (override with --save-dir), and d to discard.
  • vl dictation foreground-ptt supports --copy-on-stop, --default-stop-action <none|copy|inject|save>, --restore-clipboard-on-exit, --tmux-target-pane <pane> (auto-discovers candidate panes inside tmux and refuses to paste into its own pane), --wezterm-target-pane-id <id>, and --kitty-match <match>.
  • Persist CLI defaults with cargo run -p voicelayer-cli -- config init-defaults, config path, config show, and config set foreground_ptt.default_stop_action inject.
  • vl hotkeys portal-status checks host global hotkey support (XDG GlobalShortcuts portal on Linux, Carbon hotkeys on macOS).
  • Autostarted local provider servers store PID, lock, and log state under $XDG_RUNTIME_DIR/voicelayer/providers.
  • For installed user services on Linux or macOS, run scripts/install.sh (see User Services).
  • Always invoke Python through uv rather than the system interpreter.
