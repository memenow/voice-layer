Running voicelayerd as a user service keeps its Unix socket ready whenever vl, vl-desktop, or a global shortcut triggers dictation or composition.

One-Shot Installer

scripts/install.sh

The script runs these steps:

  1. Builds release binaries with cargo build --release --bin voicelayerd --bin vl --bin vl-desktop.
  2. Installs voicelayerd, vl, vl-desktop, and voicelayer-whisper-server-run.sh into ~/.local/bin (override with VOICELAYER_INSTALL_BIN_DIR).
  3. On Linux, copies systemd/voicelayerd.service and systemd/voicelayer-whisper-server.service into ~/.config/systemd/user/ (override with VOICELAYER_INSTALL_UNIT_DIR), reloads systemd, and restarts active units. On macOS, renders launchd/com.memenow.voicelayerd.plist into ~/Library/LaunchAgents/com.memenow.voicelayerd.plist.
  4. Seeds ~/.config/voicelayer/voicelayerd.env from systemd/voicelayerd.env.example if not already present (override directory with VOICELAYER_INSTALL_ENV_DIR).
  5. Runs vl doctor to check provider and host status.

Linux (systemd User Units)

Edit ~/.config/voicelayer/voicelayerd.env with your model paths, then enable and start the daemon:

systemctl --user enable --now voicelayerd
systemctl --user status voicelayerd
journalctl --user -u voicelayerd

macOS (LaunchAgent)

scripts/install.sh installs ~/Library/LaunchAgents/com.memenow.voicelayerd.plist with __HOME__ expanded to your home directory. Load, inspect, or unload the agent with launchctl:

launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/com.memenow.voicelayerd.plist
launchctl print "gui/$(id -u)/com.memenow.voicelayerd"
tail -f ~/Library/Logs/voicelayerd.log
launchctl bootout "gui/$(id -u)" ~/Library/LaunchAgents/com.memenow.voicelayerd.plist

Note that launchd does not load systemd EnvironmentFile files automatically. Export required VOICELAYER_* variables via EnvironmentVariables in the plist (or a wrapper script) when starting voicelayerd through launchd.

Environment Variables

~/.config/voicelayer/voicelayerd.env configures the daemon under systemd. Use absolute paths; systemd EnvironmentFile does not expand %h, %t, or shell variables inside values.

Core

  • VOICELAYER_PROJECT_ROOT: repository root used to locate python/voicelayer_worker. Required when starting outside the repository directory.
  • VOICELAYER_SOCKET_PATH: optional override for the daemon Unix socket path. Defaults to $XDG_RUNTIME_DIR/voicelayer/daemon.sock (or $TMPDIR/voicelayer/daemon.sock when XDG_RUNTIME_DIR is unset). Both voicelayerd and vl / vl-desktop honor this variable.
  • VOICELAYER_WORKER_TIMEOUT_SECONDS: timeout in seconds for worker inference RPCs (transcribe, compose, rewrite, translate). Probe RPCs use a fixed 15 s timeout. Defaults to 600.

whisper.cpp (ASR)

  • VOICELAYER_WHISPER_BIN, VOICELAYER_WHISPER_MODEL_PATH, VOICELAYER_WHISPER_TIMEOUT_SECONDS, VOICELAYER_WHISPER_NO_GPU, VOICELAYER_WHISPER_ARGS: one-shot whisper-cli settings.
  • VOICELAYER_WHISPER_SERVER_HOST, VOICELAYER_WHISPER_SERVER_PORT, VOICELAYER_WHISPER_SERVER_TIMEOUT_SECONDS: persistent whisper-server endpoint settings.
  • VOICELAYER_WHISPER_SERVER_AUTO_START, VOICELAYER_WHISPER_SERVER_BIN, VOICELAYER_WHISPER_SERVER_ARGS, VOICELAYER_WHISPER_SERVER_LAUNCH_TIMEOUT_SECONDS, VOICELAYER_WHISPER_SERVER_POLL_INTERVAL_SECONDS: worker-managed whisper-server autostart.
  • VOICELAYER_WHISPER_VAD_ENABLED, VOICELAYER_WHISPER_VAD_MODEL_PATH, VOICELAYER_WHISPER_VAD_THRESHOLD, VOICELAYER_WHISPER_VAD_MIN_SPEECH_MS, VOICELAYER_WHISPER_VAD_MIN_SILENCE_MS, VOICELAYER_WHISPER_VAD_SPEECH_PAD_MS, VOICELAYER_WHISPER_VAD_MAX_SEGMENT_SECS, VOICELAYER_WHISPER_VAD_SAMPLE_RATE: optional Silero VAD pre-pass.

Optional GPU ASR Providers

  • MiMo-V2.5-ASR: VOICELAYER_MIMO_MODEL_PATH, VOICELAYER_MIMO_TOKENIZER_PATH, VOICELAYER_MIMO_REPO_PATH, VOICELAYER_MIMO_DEVICE, VOICELAYER_MIMO_AUDIO_TAG, VOICELAYER_MIMO_TIMEOUT_SECONDS, VOICELAYER_MIMO_LONG_AUDIO_SPLIT_SECONDS, VOICELAYER_MIMO_ARGS.
  • Qwen3-ASR-1.7B: VOICELAYER_QWEN3_ASR_MODEL_PATH, VOICELAYER_QWEN3_ASR_DEVICE, VOICELAYER_QWEN3_ASR_TORCH_DTYPE (or legacy alias VOICELAYER_QWEN3_ASR_DTYPE), VOICELAYER_QWEN3_ASR_TIMEOUT_SECONDS, VOICELAYER_QWEN3_ASR_LONG_AUDIO_SPLIT_SECONDS, VOICELAYER_QWEN3_ASR_ARGS.

OpenAI-Compatible LLM

  • VOICELAYER_LLM_ENDPOINT, VOICELAYER_LLM_MODEL, VOICELAYER_LLM_API_KEY, VOICELAYER_LLM_TIMEOUT_SECONDS.
  • VOICELAYER_LLM_AUTO_START, VOICELAYER_LLAMA_SERVER_BIN, VOICELAYER_LLAMA_MODEL_PATH, VOICELAYER_LLAMA_HF_REPO, VOICELAYER_LLAMA_SERVER_ARGS, VOICELAYER_LLAMA_LAUNCH_TIMEOUT_SECONDS, VOICELAYER_LLAMA_POLL_INTERVAL_SECONDS.

Client-Side Only (vl-desktop)

VOICELAYER_DAEMON_BIN and VOICELAYER_LOG are read by vl-desktop rather than voicelayerd and are excluded from voicelayerd.env. See Desktop Shell.

Persistent whisper-server (Linux)

Running whisper-server persistently keeps the ggml model mapped across requests instead of reloading on every capture. Pick one management mode:

Option When to use it Managed by
VOICELAYER_WHISPER_SERVER_AUTO_START=true in voicelayerd.env Lazy startup on the first transcription call, tied to the worker. voicelayerd
systemctl --user enable --now voicelayer-whisper-server Always running on login with separate journald logs and restart policy. systemd unit

Do not enable both simultaneously or both will contend for the same port. Leave VOICELAYER_WHISPER_SERVER_AUTO_START unset or false when using the dedicated unit.

Enable the Dedicated Unit

# Required in ~/.config/voicelayer/voicelayerd.env:
#   VOICELAYER_WHISPER_SERVER_BIN=/absolute/path/to/whisper-server
#   VOICELAYER_WHISPER_MODEL_PATH=/absolute/path/to/ggml-base.en.bin
#   VOICELAYER_WHISPER_SERVER_PORT=8188
systemctl --user enable --now voicelayer-whisper-server
systemctl --user status voicelayer-whisper-server
journalctl --user -u voicelayer-whisper-server

The unit runs voicelayer-whisper-server-run.sh, which validates environment variables, tokenizes VOICELAYER_WHISPER_SERVER_ARGS with Python's shlex.split, and calls exec so systemd tracks the server PID directly. Check vl doctor for whisper_mode: "server".

Docker Drop-In Override

To run the container image ghcr.io/ggml-org/whisper.cpp:main instead of a host binary, create a systemd drop-in:

mkdir -p ~/.config/systemd/user/voicelayer-whisper-server.service.d
cat > ~/.config/systemd/user/voicelayer-whisper-server.service.d/docker.conf <<'EOF'
[Service]
ExecStart=
ExecStart=/usr/bin/docker run --rm --name voicelayer-whisper-server \
  -p 127.0.0.1:8188:8188 \
  -v %h/.cache/voicelayer/models:/models:ro \
  --entrypoint whisper-server \
  ghcr.io/ggml-org/whisper.cpp:main \
  -m /models/ggml-base.en.bin \
  --host 0.0.0.0 --port 8188 -ng
ExecStop=/usr/bin/docker stop voicelayer-whisper-server
EOF
systemctl --user daemon-reload
systemctl --user restart voicelayer-whisper-server

Manual Install (Linux)

cargo build --release --bin voicelayerd --bin vl --bin vl-desktop
install -m 0755 target/release/voicelayerd ~/.local/bin/voicelayerd
install -m 0755 target/release/vl ~/.local/bin/vl
install -m 0755 target/release/vl-desktop ~/.local/bin/vl-desktop
install -m 0755 scripts/voicelayer-whisper-server-run.sh \
  ~/.local/bin/voicelayer-whisper-server-run.sh
install -d ~/.config/systemd/user ~/.config/voicelayer
install -m 0644 systemd/voicelayerd.service ~/.config/systemd/user/voicelayerd.service
install -m 0644 systemd/voicelayer-whisper-server.service \
  ~/.config/systemd/user/voicelayer-whisper-server.service
[[ -f ~/.config/voicelayer/voicelayerd.env ]] || \
  install -m 0600 systemd/voicelayerd.env.example ~/.config/voicelayer/voicelayerd.env
systemctl --user daemon-reload
systemctl --user enable --now voicelayerd

Uninstall

Linux:

systemctl --user disable --now voicelayerd voicelayer-whisper-server
rm -f ~/.config/systemd/user/voicelayerd.service \
      ~/.config/systemd/user/voicelayer-whisper-server.service
rm -f ~/.local/bin/voicelayerd \
      ~/.local/bin/vl \
      ~/.local/bin/vl-desktop \
      ~/.local/bin/voicelayer-whisper-server-run.sh
systemctl --user daemon-reload

macOS:

launchctl bootout "gui/$(id -u)" ~/Library/LaunchAgents/com.memenow.voicelayerd.plist
rm -f ~/Library/LaunchAgents/com.memenow.voicelayerd.plist
rm -f ~/.local/bin/voicelayerd \
      ~/.local/bin/vl \
      ~/.local/bin/vl-desktop \
      ~/.local/bin/voicelayer-whisper-server-run.sh

Files under ~/.config/voicelayer/ are preserved for future reinstalls.
