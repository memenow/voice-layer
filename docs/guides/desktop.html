vl-desktop is an interactive iced::daemon GUI shell that talks to voicelayerd over the same /v1 Unix socket as vl. Because it runs as an interactive desktop app rather than a background service, its client-side settings stay separate from ~/.config/voicelayer/voicelayerd.env.

Launch

vl-desktop

If voicelayerd is not running yet, the window displays a Start daemon button that launches voicelayerd and waits for socket readiness.

GUI Panels

The sidebar provides eight tabs: Dictation, Compose, Rewrite, Translate, Providers, Doctor, History, and Settings.

Dictation

Start and stop live dictation from the main action button or the registered global shortcut. While active, the panel shows the current stage and renders the completed transcript and detected language upon stop.

The capture options card exposes per-session settings: ASR provider selector, optional input language tag (blank for auto-detect), segmentation mode (One-shot, Fixed window, or VAD-gated), and a translate-to-English toggle. A bounded capture button calls POST /v1/dictation/capture for a single timed clip and is disabled while a live session is active.

Compose, Rewrite, Translate

Each tab submits to its matching /v1 endpoint and displays the returned PreviewArtifact. Once ready, an injection card lets you choose an InjectTarget, toggle auto_submit, and call POST /v1/inject to inspect the computed InjectionPlan without typing into another window automatically.

  • Compose: spoken prompt, optional archetype (email, issue, technical summary, etc.), and optional output language.
  • Rewrite: source text, style preset, and optional output language.
  • Translate: source text and required target language.

Providers, Doctor, History

  • Providers: lists registered ProviderDescriptor entries with kind, transport, and local/remote status.
  • Doctor: displays daemon health, socket path, ASR and LLM configuration/reachability, and global hotkey availability, with an on-demand re-probe button (POST /v1/health/refresh).
  • History: lists recent CaptureSession records from GET /v1/sessions.

Settings

Stores GUI-only workflow defaults locally in desktop.toml:

  • Default output language (blank preserves source language)
  • Default inject target
  • One-shot capture window duration (5, 8, 12, 20, or 30 seconds)
  • Surface opacity slider (0% to 100%) and Reduce Transparency toggle

Live OS accessibility settings (Increase Contrast and Reduce Motion) are read from the desktop environment and displayed read-only.

Capture HUD Overlay

During live dictation or bounded capture, vl-desktop opens a borderless floating HUD pill showing capture state, a time-driven animated waveform, and a Stop control during live dictation.

Always-on-top and centered placement are requested as compositor hints (Position::Centered). Compositors such as KWin and wlroots honor them; GNOME Wayland controls window placement directly and ignores always-on-top hints without layer-shell support.

System Tray

Enabling the optional tray Cargo feature on Linux compiles in a StatusNotifierItem tray icon backed by ksni with three stateless actions: Toggle dictation, Show VoiceLayer, and Quit VoiceLayer. On GNOME Shell, displaying the tray requires the AppIndicator/KStatusNotifierItem extension; if no host is present, the app logs once and runs normally without a tray.

Rendering and Accessibility

vl-desktop layers an animated wgpu/WGSL backdrop shader over an opaque gradient fallback:

  • On Wayland, fragment shaders cannot sample the desktop framebuffer behind the window, so translucent cards composite over the in-window backdrop rather than real desktop blur.
  • If GPU rendering is unavailable, iced falls back to its tiny-skia software renderer where the custom shader is a no-op and the opaque gradient backdrop remains cleanly visible.
  • Surface opacity and Reduce Transparency persist in desktop.toml. When OS Reduce Motion is enabled, shader frame ticks pause automatically.

Environment Variables

Variable Purpose Default
VOICELAYER_DAEMON_BIN Path to the voicelayerd binary spawned by the Start daemon button. $HOME/.local/bin/voicelayerd if present, then $PATH lookup
VOICELAYER_LOG tracing_subscriber env-filter for vl-desktop logs (target=level[,target=level]*). vl_desktop=info

These variables are client-side only and are intentionally excluded from systemd/voicelayerd.env.example (enforced by tests/python/test_env_example.py). Set them in your shell profile or desktop launcher if needed.

Relationship to the Daemon

  • vl-desktop uses the same VOICELAYER_SOCKET_PATH resolution as vl (see User Services).
  • Live session updates, segmentation progress, and failures flow over the shared GET /v1/events/stream SSE connection.

Global Hotkey

On Linux, vl-desktop registers the global shortcut voicelayer.dictation_toggle via org.freedesktop.portal.GlobalShortcuts. On macOS, it registers a system hotkey via global-hotkey (Carbon RegisterEventHotKey). Both invoke the same live dictation start/stop flow as the GUI buttons. When global hotkeys are unavailable, vl-desktop falls back to window-focused F9.

For terminal workflows without the GUI, use vl dictation foreground-ptt.
