VoiceLayer

VoiceLayer is a local-first voice composition layer for Ubuntu and macOS (Apple Silicon) desktops. It provides low-latency dictation, structured text composition, rewriting, and translation through a local daemon, a CLI/TUI, a desktop GUI, and target-specific host adapters.

Scope. VoiceLayer targets browser text fields, editors and IDEs, terminal multiplexers (tmux, WezTerm, Kitty), and drafting workflows that benefit from a preview step before insertion. It is not an IME candidate window, a subtitle-only transcriber, or a cloud-only voice assistant.

Capabilities

  • Rust workspace with voicelayer-core (shared domain, config, and HTTP client), voicelayerd (daemon and /v1 Unix socket API), voicelayer-cli (vl CLI/TUI), voicelayer-desktop (vl-desktop iced GUI), voicelayer-ui (shared UI theme tokens), and voicelayer-testkit (doc/test helpers).
  • Live dictation with one-shot, fixed-window segmented, and Silero VAD-gated capture, per-session ASR provider selection, and Server-Sent Events on /v1/events/stream.
  • Optional Silero VAD pre-pass in the Python worker that trims non-speech before transcription across whisper.cpp, MiMo-V2.5-ASR, and Qwen3-ASR-1.7B.
  • Local ASR via whisper.cpp (whisper-cli or persistent whisper-server with optional autostart), plus opt-in GPU backends (Xiaomi MiMo-V2.5-ASR and Apache-2.0 Alibaba Qwen3-ASR-1.7B).
  • Composition, rewrite, and translation over any OpenAI-compatible chat completions endpoint, with optional llama-server autostart for local endpoints.
  • Persistent Rust-to-Python JSON-RPC bridge over stdio so large ASR models stay warm in memory across requests.
  • User service definitions for Linux (systemd user units) and macOS (LaunchAgent), installed by scripts/install.sh.

Quick Start

Build the release binaries, sync the Python worker environment, and start the daemon from the repository root:

cargo build --release --bin voicelayerd --bin vl --bin vl-desktop
uv sync --group dev
cargo run -p voicelayerd

Check daemon health and registered providers:

cargo run -p voicelayer-cli -- doctor
cargo run -p voicelayer-cli -- providers

Record and transcribe a short clip, drive a live dictation session, or open the terminal push-to-talk panel:

cargo run -p voicelayer-cli -- record-transcribe --duration-seconds 8 --language auto
cargo run -p voicelayer-cli -- dictation start --language auto
cargo run -p voicelayer-cli -- dictation stop <session-id>
cargo run -p voicelayer-cli -- dictation foreground-ptt --language auto
