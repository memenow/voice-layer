Purpose

Isolating model integration behind a JSON-RPC worker boundary lets ASR and LLM backends evolve independently of the Rust daemon and desktop clients.

Transport

  • Protocol: JSON-RPC 2.0 over line-delimited stdio.
  • Lifecycle: crates/voicelayerd/src/worker/mod.rs spawns one persistent worker subprocess per WorkerCommand and serializes calls behind an async mutex. Immediately after spawn, the daemon sends an initialize handshake carrying the typed provider configuration parsed from VOICELAYER_* environment variables.
  • Recovery: WorkerCommand::call respawns the subprocess if it exits unexpectedly, closes stdout, or times out. A rolling tail of worker stderr lines is buffered and attached to crash errors so Python tracebacks remain visible in daemon diagnostics.
  • Environment reloads: provider configuration is snapshotted at worker initialization; restart voicelayerd (or terminate the worker child) to apply updated VOICELAYER_* variables.
  • Interpreter policy: the daemon launches the worker via uv run against the repository environment rather than the system Python interpreter.

Required Methods

  • initialize (first frame after spawn; supplies typed provider configuration)
  • health
  • list_providers
  • compose
  • rewrite
  • translate
  • transcribe
  • segment_probe
  • stitch_wav_segments

Method Behavior

  • initialize: stores the daemon's provider configuration payload for the worker session. If a standalone caller invokes another method before initialize, the worker initializes lazily from VOICELAYER_* environment variables.
  • health: reports whisper mode (server, cli, or unconfigured), MiMo-V2.5-ASR and Qwen3-ASR-1.7B readiness, and live /v1/models probe status for the configured OpenAI-compatible LLM endpoint.
  • list_providers: returns descriptors for whisper.cpp, optional GPU ASR providers, and the configured LLM endpoint.
  • transcribe: runs one shared Silero VAD pre-pass in python/voicelayer_worker/pipeline.py when enabled (trimming non-speech or short-circuiting pure silence to an empty transcript), then dispatches to the selected backend:
    • Default or provider_id="whisper_cpp": prefers whisper-server when configured and falls back to whisper-cli on error or when unconfigured.
    • provider_id="mimo_v2_5_asr": routes directly to providers/mimo_asr.py without whisper fallback.
    • provider_id="qwen3_asr_1_7b": routes directly to providers/qwen3_asr.py without whisper fallback.
    • Unrecognized provider_id values fail with -32004 instead of falling back to whisper.
    Per-call temporary WAV files (VAD outputs and long-audio split chunks) are removed in finally blocks while preserving the caller's original audio capture.
  • compose, rewrite, and translate: call the configured OpenAI-compatible chat completions endpoint via providers/openai_compatible.py, optionally auto-starting llama-server when VOICELAYER_LLM_AUTO_START=true.
  • segment_probe: runs Silero VAD on a short WAV probe via python/voicelayer_worker/vad.py and returns {has_speech, speech_ratio, regions, notes}. Returns -32004 when VAD is unconfigured and -32005 on VAD runtime failure.
  • stitch_wav_segments: concatenates compatible WAV segments into one WAV file via python/voicelayer_worker/audio.py and returns {audio_file, segment_count, duration_secs}. Rejects invalid inputs with -32600 and format mismatches with -32005.

Error Policy

  • Parse error: -32700
  • Invalid JSON-RPC request: -32600
  • Method not found: -32601
  • Provider unavailable or unconfigured: -32004
  • Provider request failed at runtime: -32005

Preview Payload Shape

compose, rewrite, and translate return a preview object with the following fields:

{
  "title": "string",
  "generated_text": "string",
  "notes": ["string"]
}

Module Layout

The worker package lives under python/voicelayer_worker/:

  • python/voicelayer_worker/worker.py: stdio JSON-RPC loop, request framing, and method dispatch.
  • python/voicelayer_worker/pipeline.py: unified Silero VAD pre-pass, ASR backend routing, health aggregation, and provider dispatch.
  • python/voicelayer_worker/config.py: frozen configuration dataclasses loaded from the initialize payload or environment.
  • python/voicelayer_worker/protocol.py: JSON-RPC constants and request/response helpers.
  • python/voicelayer_worker/errors.py: ProviderInvocationError and error codes.
  • python/voicelayer_worker/audio.py: stdlib wave helpers for duration inspection, long-audio chunk splitting, and segment stitching.
  • python/voicelayer_worker/vad.py: Silero VAD (v4 and v5 ONNX) speech-region detection, WAV trimming, and probe classification. Lazy-imports numpy and onnxruntime.
  • python/voicelayer_worker/process.py: shared background process autostart, lock-file reclamation, and HTTP readiness polling.
  • python/voicelayer_worker/transcript.py: transcript normalization and chunk joining helpers.
  • python/voicelayer_worker/providers/registry.py: provider catalog descriptors.
  • python/voicelayer_worker/providers/whisper_cli.py: one-shot whisper-cli subprocess execution.
  • python/voicelayer_worker/providers/whisper_server.py: persistent whisper-server HTTP client, multipart encoder, and optional autostart.
  • python/voicelayer_worker/providers/mimo_asr.py: lazy-cached Xiaomi MiMo-V2.5-ASR backend with optional long-audio chunk splitting.
  • python/voicelayer_worker/providers/qwen3_asr.py: lazy-cached Alibaba Qwen3-ASR-1.7B backend (Apache-2.0) with optional chunk splitting.
  • python/voicelayer_worker/providers/openai_compatible.py: OpenAI-compatible chat completions client, endpoint normalization, preview formatting, and optional llama-server autostart.

Rust integration tests in crates/voicelayerd/tests/worker_protocol_guards.rs verify method parity across this document, Rust, and Python, and exercise subprocess lifecycle recovery. Python unit tests live under tests/python/.
